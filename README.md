## What is SpotiX+ Reborn?
It is a modified version of Spotify that allows you to listen ad-free, skip tracks infinitely, and much more!

Originally created by Voltan, SpotiX+ is unfortunately no longer in active development.\
Therefore, we decided to take over the project, and thus SpotiX+ Reborn was born.

## Download & Installation
Head over to the [Releases](https://github.com/AgoyaSpotix/spotixplus-reborn/releases/) section to download the latest version of the application.\
Download and run the `script.ps1` file by right-clicking it -> "Run with PowerShell".\
You will need PowerShell 7 to run this script.\
If it is not installed on your machine, you can run it using PowerShell 5 (pre-installed on Windows), and the script will automatically install PowerShell 7 for you.

## Known Issues
If you see any of the following error messages:
```
The file <path>\script.ps1 cannot be loaded because running scripts is disabled on this system
```
```
The file <path>\script.ps1 is not digitally signed.
```
Open PowerShell and run the following command:
```
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser
```
You should now be able to run the script!
